## 别让“管理任务”变成另一项任务

很多待办工具擅长收集，却让清单越积越长。Woo Todo 更关心另一件事：**下一件你真正准备完成的事是什么？**

新增任务时，只需要写标题。标签、开始日期、结束日期都可以留空；没有日期的任务会一直留在待办里，完成即止，不会因为跨日或跨周期被自动结算。需要整理时，直接输入一个标签或设置起止日期即可。

没有 Woo Todo 账号，没有联网门槛，也没有为了跨平台塞进来的浏览器运行时。任务先写入本地 SQLite；要不要同步、用哪种同步方式，都由你决定。

## 任务只有三种信息

### 标题

一句话写下要做的事。回车或保存后立即进入列表。

### 标签

标签是可选的一句话标记。新增任务时直接在输入框里输入：留空表示不添加标签；输入与已有标签相同的名称（忽略大小写）会直接复用；输入新名称会在保存任务时自动创建。Android 输入框会提示已有标签，macOS 快捷新增和任务编辑器都使用同一个输入式标签字段。也可以在 Android“更多 → 管理标签”或 macOS 任务页右上角进入管理，改名或删除已有标签。标签最多 8 个，名称和顺序会随同步空间保持一致。

### 起止日期

需要时间限制时，同时选择开始日和结束日；不设置就表示“完成即止”。过了结束日期仍未完成的任务会显示为“已逾期”，继续留在列表里，由你完成或手动放弃，不会被自动 Pass。

## 完成节奏看得见

统计页不再用“已结束周期履约率”这类周期概念，而是围绕实际完成记录：

- 本周完成、连续天数、按时率、进行中；
- 最近 14 天每日完成趋势；
- 近 30 天按标签分布；
- 最近完成与完整历史，支持多选清理。

完成、撤销完成、放弃都会留下真实记录；当前没有“自动 Pass”，统计只把明确完成的记录算进完成率和趋势。

## 它刻意做少，但把这些做好

- **本地优先**：新增、编辑、完成、删除都只依赖本机数据库，断网照常使用。
- **轻量且贴近平台**：macOS 使用 AppKit/SwiftUI，Android 使用 Kotlin/RemoteViews；不引入 Electron、Flutter 或浏览器运行时。
- **自定义标签**：默认只有“未分类”，新增任务时直接输入即可匹配已有标签或创建新标签，留空就不加标签；可以改名、删除；删除标签时该标签下的待办会归入未分类，历史记录保留原标签。
- **清晰的更新入口**：Android 检测到新版本会直接弹出“立即更新 / 稍后 / 跳过此版本”；“更多”菜单仍可随时检查。
- **显示设置留在本机**：今日标题、副标题和计时模板属于个人偏好，只保存在当前设备，不进入同步空间。
- **本机数据可彻底清理**：macOS 设置里提供“清除全部本机数据”和“卸载并清除”，会删除任务库、同步凭据、偏好、缓存与窗口恢复状态。
- **数据边界清楚**：默认只保存在设备上；启用同步时，任务正文以 AES-256-GCM 密文离开设备。

## 装好以后，从这里开始

### macOS

1. 启动后在菜单栏找到 Woo Todo；它不会占用 Dock 位置。
2. 打开“任务详情与统计…”管理统一任务列表、历史、统计与设置。
3. 任务板默认以桌面小组件模式停留在桌面层；菜单栏可切换为普通或始终置顶，右下角可拖动调整小组件宽高。用“快速新增任务”或完整任务窗口新增待办，标题下方可直接输入标签；快捷新增面板在点击其他区域后会自动收起。双击编辑，右键完成、放弃或删除。
4. 需要彻底清理时，打开“设置 → 本机数据”，选择“清除全部本机数据”或“卸载并清除”。直接拖拽卸载 `.app` 不会自动删除 Application Support、Keychain 和偏好设置。

### Android

1. 首次打开后按需授予通知权限；主界面直接显示统一任务列表。
2. 点击右下角 `+` 新建任务：填写标题，按需在标签输入框里输入已有或新标签，再设置起止日期；标签留空就是无标签，不设置日期就是完成即止。
3. 长按或点击任务行右侧菜单完成、放弃、编辑或删除；误点完成时再次勾选即可撤销。
4. 可在 Android 桌面的“微件”或“组件”入口添加 Woo Todo 今日 Widget；入口名称因系统桌面而异。

## 同步，按自己的信任边界选

Woo Todo 不要求先配置同步。单设备使用时，什么都不用做；任务始终留在本地。

- **同一网络，最快开始**：由 Mac 开启局域网同步服务，Android 扫码连接，适合设备经常处于同一网络的场景。
- **第三方 WebDAV，跨网络使用**：填写服务商提供的 HTTPS WebDAV 根目录。Woo Todo 只上传端到端加密的增量对象，服务商无法读取任务正文。
- **Cloudflare Worker + D1，自己托管**：适合希望掌控在线服务端与设备授权的人；服务端仍接触不到任务明文。

三种同步方式互斥，但都不会成为本地操作的前置条件。macOS 与 Android 都会保留已配置的局域网/自建服务和 WebDAV 身份，切回时无需重填；macOS 的 WebDAV 完整配置使用本机 AES-256-GCM 加密文件保存并自动回填。切换同时保留本地任务和标签定义，并从远端 Lamport 水位之后建立加密基线。同一网络同步会在两端绕过系统 HTTP 代理，避免 `.local` 或私有地址被错误转发；全局 TUN/VPN 模式仍需把局域网配置为直连。配置二维码和配对链接可能含有完整凭据或一次性 secret，只应在自己的设备旁展示，用完立即隐藏或清理剪贴板。

> **版本要求**：`v0.2.4` 起任务正文使用新的标签和日期语义，v0.2.3 及更早客户端无法正确理解。混用 `v0.2.5` 与 `v0.2.6` 可以同步，但请尽快同时升级。

## 数据归你，不是口号

- 本地任务保存在设备 SQLite 中，启动和编辑不依赖网络。
- WebDAV、自建服务与同一网络同步只传输 AES-256-GCM 密文及收敛所需元数据，远端不保存任务明文或 Woo Todo 登录凭据。
- 同步密钥只保存在设备安全存储中；如果所有设备和密钥同时丢失，服务端密文无法解密恢复。
- macOS 的“本机数据”页可以删除任务库、Keychain 同步身份、偏好、缓存与窗口恢复状态；云端和其他设备的数据不受影响。
- 撤销设备会阻止它继续同步，但无法远程删除已经下载到该设备的本地数据。

## 开发

两端 UI 彼此不直接依赖；macOS 与 Android 均保持原生实现。同步协议继续通过 `shared/schema/` 与 `shared/fixtures/` 对齐。常用检查命令：

```bash
npm install
npm run validate:contracts
npm run test:crypto
npm run test:backend
cargo test --manifest-path shared/core-rust/Cargo.toml --locked --all-targets
./android/gradlew -p android testDebugUnitTest
swift test --package-path macos
```

修改共享协议时，需要同时更新 JSON Schema、fixture、Swift/Kotlin 模型和后端校验。
