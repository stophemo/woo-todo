## 别让“管理任务”变成另一项任务

很多待办工具擅长收集，却让清单越积越长。Woo Todo 更关心另一件事：**下一件你真正准备完成的事是什么？**

新增任务时，只需要写标题。标签和任务日期都可以留空；没有日期的任务会一直留在待办里，完成即止，不会因为跨日或跨周期被自动结算。需要整理时，直接输入一个标签；需要安排时设置任务日期，只有跨天任务才需要再选结束日期。

没有 Woo Todo 账号，没有联网门槛，也没有为了跨平台塞进来的浏览器运行时。任务先写入本地 SQLite；要不要同步由你决定，开启后使用你自己的 WebDAV 账号同步。

## 任务只有三种信息

### 标题

一句话写下要做的事。回车或保存后立即进入列表。

### 标签

标签是可选的一句话标记。新增任务时直接在输入框里输入：留空表示不添加标签；输入与已有标签相同的名称（忽略大小写）会直接复用；输入新名称会在保存任务时自动创建。Android 输入框会提示已有标签，macOS 快捷新增和任务编辑器都使用同一个输入式标签字段。也可以在 Android“更多 → 管理标签”或 macOS 任务页右上角进入管理，改名、删除或调整标签顺序：Android 拖动左侧手柄，macOS 使用上下箭头。管理列表越靠上优先级越高，在任务时间相同时会优先展示高优先级标签的任务；“未分类”也可以移动。标签最多 8 个，名称和顺序会随同步空间保持一致。

### 任务日期与可选结束日期

任务通常只有一个任务日期；需要跨天执行时，再打开“设置结束日期”补充结束日期。不设置任务日期就表示“完成即止”。列表按任务日期从近到远排列，没有任务日期的任务排在最后；过了结束日期仍未完成的任务会显示为“已逾期”，继续留在列表里，由你完成或手动放弃，不会被自动 Pass。

### 重复

需要每天做的任务（例如铲屎）可以打开“每天重复”。每天会生成一条新任务；前一天未完成时，会在下一次结算时自动记为“已放弃”并生成下一条，历史里能看到漏做记录。已完成的任务则会正常生成下一条。每天重复任务必须设置任务日期；可在 macOS 或 Android 的任务编辑器中设置，也可以通过 MCP 的 `recurrence=daily` 设置。低于 `v0.2.16` 的客户端会把每天重复任务当作一次性任务显示，建议两端同时升级。

### 提醒

每条任务可以选择在任务日期当天的某个时间提醒。macOS 的“设置 → 提醒”和 Android 的“更多 → 晚间任务提醒”还可以开启每日汇总：到达指定时间后，用一条通知列出明天要做的事；这项汇总提醒默认按设备保存，不随同步空间下发。

## 完成节奏看得见

统计页不再用“已结束周期履约率”这类周期概念，而是围绕实际完成记录：

- 本周完成、连续天数、按时率、进行中；
- 最近 14 天每日完成趋势；
- 近 30 天按标签分布；
- 最近完成与完整历史，支持多选清理。

完成、撤销完成、放弃都会留下真实记录；当前没有“自动 Pass”，统计只把明确完成的记录算进完成率和趋势。

## 它刻意做少，但把这些做好

- **本地优先**：新增、编辑、完成、删除都只依赖本机数据库，断网照常使用。
- **每天重复**：显式设置重复的任务按天生成；漏做会记录为放弃，不会悄悄消失。
- **轻量且贴近平台**：macOS 使用 AppKit/SwiftUI，Android 使用 Kotlin/RemoteViews；不引入 Electron、Flutter 或浏览器运行时。
- **自定义标签**：默认只有“未分类”，新增任务时直接输入即可匹配已有标签或创建新标签，留空就不加标签；可以改名、删除和上下调整优先级；删除标签时该标签下的待办会归入未分类，历史记录保留原标签。
- **清晰的更新入口**：Android 检测到新版本会直接弹出“立即更新 / 稍后 / 跳过此版本”；“更多”菜单仍可随时检查。
- **显示设置留在本机**：今日标题、副标题和计时模板属于个人偏好，只保存在当前设备，不进入同步空间。
- **本机数据可彻底清理**：macOS 设置里提供“清除全部本机数据”和“卸载并清除”，会删除任务库、同步凭据、偏好、缓存与窗口恢复状态。
- **数据边界清楚**：默认只保存在设备上；启用同步时，任务正文以 AES-256-GCM 密文离开设备。

## 装好以后，从这里开始

### macOS

1. 打开下载的 DMG，把 `Woo Todo.app` 拖到“应用程序”，再从“应用程序”启动。首次打开如果提示“无法验证开发者”，到“系统设置 → 隐私与安全性”点“仍要打开”，或右键应用选择“打开”。DMG 与 ZIP 的首次打开提示相同；ZIP 只用于 Sparkle 自动更新。
2. 启动后在菜单栏找到 Woo Todo；它不会占用 Dock 位置。
3. 从菜单栏“打开 Woo Todo”或按 `⌘0` 打开独立主窗口。主窗口包含今天、全部任务、历史、统计和最近删除；设置是单独窗口，通过主窗口左下角“设置…”或 `⌘,` 打开。`⌘W` 收起主窗口，菜单栏可再次打开；主窗口显示时会临时出现 Dock 图标，全部收起后回到菜单栏应用。
4. 任务板默认以桌面小组件模式停留在桌面层，点击桌面空白触发“显示桌面”时不会被收起；菜单栏的“始终置顶”会临时浮到其他窗口上方，关闭置顶后自动回到桌面小组件，“鼠标穿透”也不会退出小组件模式。右下角可拖动调整小组件宽高。桌面小组件位于 Finder 图标下方，新增桌面文件不会被遮住；但 Finder 不支持为第三方窗口预留桌面图标区，图标仍可能与任务板重叠。指针移入面板时会临时抬到图标上方以保持可点击。用“快速新增任务”或完整任务窗口新增待办，标题下方可直接输入标签；需要安排时展开“日期与提醒”，设置任务日期、可选的结束日期和当天提醒时间。快捷新增面板在点击其他区域后会自动收起，设置窗口可按 `⌘W` 关闭。任务页右上角“管理标签”可调整标签优先级。双击编辑，右键完成、放弃或删除；删除的任务会先进入“最近删除”，可随时恢复，恢复后会像新增任务一样同步到其他设备。“设置 → 跨设备”先填写同一个 WebDAV 账号，第一台设备建立同步空间，其他设备可以直接扫描邀请二维码加入，或用六位配对码加入；也可以反向输入新设备显示的六位码并批准。
5. 需要彻底清理时，打开“设置 → 本机数据”，选择“清除全部本机数据”或“卸载并清除”。直接拖拽卸载 `.app` 不会自动删除 Application Support、Keychain 和偏好设置。
6. 如果想让本机 MCP 客户端直接把计划写入待办，打开“设置 → MCP 服务”，开启“开放 MCP 服务”并复制对应 Agent 的命令；服务只监听 `127.0.0.1`，需要携带令牌，Woo Todo 退出后停止。

### Android

1. 首次打开后按需授予通知权限；主界面直接显示统一任务列表。“更多 → 晚间任务提醒”可以开关每日汇总并调整时间。“更多 → 跨设备”先配置同一个 WebDAV 账号；已有空间时，让对方生成邀请二维码扫码加入，或输入另一台设备显示的六位配对码；也可以显示本机的六位码让对方批准。
2. 点击右下角 `+` 新建任务：填写标题，按需在标签输入框里输入已有或新标签，再设置任务日期；只有跨天任务才需要打开“设置结束日期”。标签留空就是无标签，不设置任务日期就是完成即止。需要调整标签优先级时，打开“更多 → 管理标签”，拖动左侧手柄调整顺序。
3. 长按或点击任务行右侧菜单完成、放弃、编辑或删除；误点完成时再次勾选即可撤销。删除的任务会先进入“更多 → 最近删除”，可随时恢复；恢复后会像新增任务一样同步到其他设备。
4. 可在 Android 桌面的“微件”或“组件”入口添加 Woo Todo 今日 Widget；入口名称因系统桌面而异。

## 跨设备同步空间

Woo Todo 不要求先配置同步。单设备使用时，什么都不用做；任务始终留在本地。需要跨设备时，macOS 与 Android 都通过你自己选择的 WebDAV 服务同步，不再依赖 Worker 或局域网。

- **供应商自选**：坚果云、Nextcloud、群晖或任何兼容的 HTTPS WebDAV 服务都可以；所有设备使用同一个账号与目录。建议使用供应商提供的应用专用密码，而不是登录密码。
- **每台设备先配置账号**：在“跨设备”里选择服务商，填写账户与应用密码即可；坚果云会自动带出通用地址，也可自行修改。新账号会自动使用该地址下的 `WooTodo` 专属文件夹，不会和同一 WebDAV 账号下的其他应用混在一起；已有同步空间沿用原目录。保存前会测试目录读写。账号与应用密码在本机加密保存：macOS 使用 AES-256-GCM 加密文件，Android 使用 Keystore 包裹。
- **邀请二维码最快**：已同步设备点「邀请新设备」生成二维码或邀请文本，新设备直接扫描或粘贴即可，自动带过地址、账号与同步密钥；邀请 10 分钟内有效，包含应用密码，只应给自己的设备使用；两端都需要 v0.2.26 及以上，旧版本仍可用六位配对码。加入前会确认是否清空本机任务与旧身份。
- **六位码配对**：已有设备可以显示六位配对码，新设备输入；新设备也可以显示自己的六位码，由已有设备输入。持有空间的一方看到加入方设备名后点一次「批准加入」，加入方自动完成，配对码 5 分钟内有效。两方都有空间时，加入方选择以哪台设备的数据为准；只有选择对方数据时，才会在批准成功后清空本机任务并加入，取消或对方不批准不会清空本机数据。
- **端到端加密**：任务正文与标签以 AES-256-GCM 密文写入 WebDAV，配对时通过 X25519 传递同步密钥；供应商只能看到密文、公钥、设备名与配对码，无法读取任务明文或同步密钥。
- **同步时机**：启动、本地修改、回到前台以及每 15 分钟兜底时同步；连续编辑会合并成一次同步。WebDAV 没有服务端推送，其他设备的变更会在下次同步时到达，不是实时同步。
- **请求按批合并**：同一目录一轮只创建一次，待上传操作分批连续推送，拉取最多 4 路并发；首次加入已有空间时会先分批上传本机任务，再拉取历史，期间可能连续显示几次同步。
- **设备列表**：每台设备最多每 15 分钟写入一次加密心跳，其他设备可以查看设备名、平台和最近同步时间。这是尽力而为的名册，可能不是最新状态，也不能远程吊销；退出空间只清除本机身份，要阻止旧设备继续同步请在 WebDAV 供应商处修改应用密码。
- **旧方式已停用**：旧 Worker 与局域网同步凭据保留但不会启用，本地任务保留，应用会提示重新配置 WebDAV；旧版 0.2.x 的 WebDAV 完整凭据会自动迁移并继续同步。

同步不会成为本地操作的前置条件：断网时仍可新增、编辑、完成和删除，WebDAV 恢复可达后自动补齐。供应商的请求频率和流量限制可能影响同步速度。

> **版本要求**：`v0.2.4` 起任务正文使用新的标签和日期语义，v0.2.3 及更早客户端无法正确理解。`v0.2.7` 至 `v0.2.26` 的 WebDAV 客户端可以互相同步；`v0.2.6` 及更早客户端不保留“未分类”的自定义排序位置，建议两端同时升级。

## 让本机 Agent 通过 MCP 直接写入计划

macOS 设置里的“MCP 服务”可以开放本机 MCP 服务：Claude Code 等本机 Agent 不必再让你复制粘贴，而是直接查询、新增、编辑、完成、撤销完成、放弃、删除和恢复任务，管理标签并读取统计。

- 只监听本机回环地址，使用设置页生成并持久化的五位随机端口，仅限本机其他 Agent 调用，不会暴露到局域网或互联网；每个请求都需要 Bearer 令牌。
- 服务运行在 Woo Todo 进程内，不额外启动后台进程；多个 Agent 共用同一个地址。关闭开关或退出应用立即停止；任务仍只写入本机 SQLite，不会把任务明文发送到云端。
- 支持 Claude Code、Codex、Pi、Hermes，以及 Cursor、VS Code 等支持 HTTP MCP 的客户端；设置页可直接复制对应命令或 JSON 配置。
- 写入前先用 `list_tasks` 取得任务 UUID；`delete_task` 会进入最近删除，`restore_task` 会以新 id 恢复；`purge_trash` 和 `clear_history` 是永久操作，必须显式确认。
- `add_task` / `update_task` 支持 `recurrence=daily`；服务端口为首次生成后固定的五位随机端口，冲突时会自动更换，届时按设置页重新复制 Agent 命令。

```bash
claude mcp add --transport http woo-todo http://127.0.0.1:<设置页端口>/mcp \
  --header "Authorization: Bearer <MCP 服务页显示的令牌>"
```

## 数据归你，不是口号

- 本地任务保存在设备 SQLite 中，启动和编辑不依赖网络。
- WebDAV 只保存 AES-256-GCM 密文及同步所需的元数据；供应商不接触任务明文。
- 同步密钥只保存在设备安全存储中；WebDAV 应用密码由本机保存并仅用于访问你选择的 WebDAV 服务。如果所有设备和密钥同时丢失，WebDAV 上的密文无法解密恢复。
- macOS 的“本机数据”页可以删除任务库、同步凭据、偏好、缓存与窗口恢复状态；WebDAV 和其他设备的数据不受影响。
- WebDAV 没有远程吊销；退出同步空间只清除本机身份。要阻止旧设备继续同步需修改 WebDAV 应用密码，但无法远程删除已经下载到该设备的本地数据。

## 开发

两端 UI 彼此不直接依赖；macOS 与 Android 均保持原生实现。同步协议继续通过 `shared/schema/` 与 `shared/fixtures/` 对齐。常用检查命令：

```bash
npm install
npm run validate:contracts
npm run test:crypto
npm run test:backend
cargo test --manifest-path shared/core-rust/Cargo.toml --locked --all-targets
./android/gradlew -p android testDebugUnitTest
swift test --package-path macos
```

修改共享协议时，需要同时更新 JSON Schema、fixture、Swift/Kotlin 模型和后端校验。
