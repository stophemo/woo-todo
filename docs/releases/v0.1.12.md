# Woo Todo v0.1.12

这一版正式交付 Windows 原生客户端，并用 Rust 共享核心统一 Windows 的任务规则、SQLite 仓储语义和通知计划。macOS、Android 继续保留各自的原生交互与系统能力。

## 主要变化

### Windows 10/11 原生客户端

- 新增 Windows 10 build 19041+ 与 Windows 11 x64 客户端，使用 WPF、Win32 和 WinRT，不包含 Electron、WebView 或跨端 UI 运行时。
- 提供完整任务窗口、系统托盘、可置顶或鼠标穿透的悬浮任务板，以及 `Ctrl + Alt + 1` 至 `Ctrl + Alt + 4` 全局快捷键。
- 任务提醒交给 Windows 系统调度，应用退出后仍可触发；点击通知会激活已有实例并打开对应任务。
- EXE 为包含 .NET 运行时的当前用户自包含安装包，支持开始菜单快捷方式、可选桌面快捷方式、覆盖升级和标准卸载。

### Rust 共享核心

- 新增 Rust 共享领域核心，覆盖任务校验、周期结算、重复任务、统计、SQLite 仓储语义和稳定通知计划。
- Windows 通过窄 C ABI/JSON 接入共享核心；macOS 与 Android 按能力渐进迁移，不重写已有原生 UI、Widget、通知与安全存储。
- CI 增加 Rust 全量测试、Clippy、Windows .NET 测试和真实 Inno Setup 安装包验证。

### 发布与文档

- README、安装指南和产品主页补充 Windows 能力、系统要求与下载入口。
- 正式 Release 现在统一生成 Android APK、macOS ZIP、Windows x64 EXE 和 `SHA256SUMS.txt`。

## 下载

- `Woo-Todo-v0.1.12-android.apk`：Android 13+，使用项目长期 Release 签名，可直接覆盖升级。
- `Woo-Todo-v0.1.12-macos-arm64.zip`：Apple Silicon macOS 应用，使用 ad-hoc 签名，未经过 Apple 公证。
- `Woo-Todo-v0.1.12-windows-x64-setup.exe`：Windows 10 build 19041+ / Windows 11 x64 自包含安装器，当前未做代码签名。
- `SHA256SUMS.txt`：三个安装包的 SHA-256 校验值。

Windows 首版聚焦本地任务、统计、悬浮任务板、托盘、快捷键和系统提醒，暂不包含 macOS/Android 已有的坚果云或 Worker 同步与加密备份。未签名 EXE 可能触发 SmartScreen，请只从本仓库 Release 下载并核对 SHA-256。
