这一版将 Windows 客户端改为真正轻量的 Rust + `windows-rs` + Win32 原生免安装程序，同时补齐误操作回退，并让悬浮窗透明度与鼠标穿透可以分别控制。

## 主要变化

### Windows 原生免安装版

- Windows 客户端已从 WPF/.NET 重构为 Rust、`windows-rs`、Win32 和 WinRT，不包含 .NET、Electron、WebView 或跨端 UI 运行时。
- Windows 只发布 ZIP，压缩包内仅有一个原生 x64 `WooTodo.exe`；解压即可运行，不需要安装、管理员权限或额外下载运行环境。
- 首次运行会为当前用户配置开始菜单身份和 `wootodo://` 协议，以支持系统通知与已有实例唤醒；不会复制 EXE，也不会写入系统级目录。
- 本地任务和设置保存在 `%LOCALAPPDATA%\Woo Todo`，主要文件为 `woo-todo.sqlite3` 和 `settings.json`。

### 交互修正

- 已完成的任务可以再次点击取消完成，任务状态支持 `pending → completed → pending`，误点后可以直接回退。
- 悬浮窗透明度与鼠标穿透改为两个独立设置；低透明度不再强制开启穿透，切换穿透也不会改动已经选择的透明度。
- 透明度和鼠标穿透设置会持久化，退出并重新打开应用后保持不变。

### Windows 自动验证

- GitHub Windows Runner 会对最终发布 ZIP 执行完整烟测，而不只验证编译通过。
- 烟测覆盖原生窗口启动、单实例和窗口唤醒、开始菜单身份、`wootodo://`、快速新增、完成与取消完成、透明度与穿透独立、托盘退出，以及 SQLite 和设置重启持久化。
- 发布工作流会确认 ZIP 仅包含 AMD64 `WooTodo.exe`，并与 Android APK、macOS App ZIP 一同生成 `SHA256SUMS.txt`。

## 下载

- `Woo-Todo-v0.1.13-android.apk`：Android 13+ 安装包，使用项目长期 Release 签名，可直接覆盖升级。
- `Woo-Todo-v0.1.13-macos-arm64.zip`：内含 `Woo Todo.app` 的 Apple Silicon macOS 免安装 ZIP，使用 ad-hoc 签名，未经过 Apple 公证。
- `Woo-Todo-v0.1.13-windows-x64.zip`：内含单个 `WooTodo.exe` 的 Windows 10 build 19041+ / Windows 11 x64 免安装 ZIP，当前未做代码签名。
- `SHA256SUMS.txt`：三个发布文件的 SHA-256 校验值。

运行未签名的 Windows 程序时，SmartScreen 可能提示来源未知。请只从本仓库 Release 下载并核对 SHA-256。已经安装早期 Windows 安装包的用户，应先退出并卸载旧程序，再运行 ZIP 中的新版本；卸载不会删除 `%LOCALAPPDATA%\Woo Todo` 中的本地任务和设置。
