本版补齐误操作恢复、显示设置同步和三端应用内更新，并将官网的视觉语言落到原生客户端。

## 功能更新

- macOS、Android 与 Windows 均可取消当前周期内误点完成的任务；撤销操作会按 `reopen` 协议同步，不会生成重复任务。
- macOS 与 Android 的任务板显示设置支持跨设备同步；新设备默认值不会反向覆盖已有远端配置。
- 鼠标穿透与透明度彻底解绑，开启或关闭穿透不再自动改写透明度。
- 修正 macOS“设置 → 快捷键”的控件布局和文字空间。
- 三端采用深墨色、暖白、紫色主操作与绿色完成状态；macOS、Windows 悬浮板增加今日进度，Android 首页与 Widget 同步调整。

## 应用内更新

- macOS 接入 Sparkle 2：检查到新版本后可在应用内下载、校验、替换并重启；更新 ZIP 使用独立 EdDSA 签名。
- Android 在应用内下载 APK，核对包名、版本和正式签名后交给系统安装器；首次使用需要授予 Woo Todo“安装未知应用”权限，Android 仍会显示系统安装确认。
- Windows 从托盘检查更新，后台下载免安装 ZIP，核对 GitHub Release 的 SHA-256 digest 后由临时 helper 替换 `WooTodo.exe` 并重启；任务和设置仍保存在 `%LOCALAPPDATA%\Woo Todo`。
- `v0.1.13` 尚未内置更新器，因此升级到本版仍需手动下载一次；安装 `v0.1.14` 后，后续版本可使用应用内更新。

## 测试与发布

- Windows Runner 继续执行 Rust 测试、MSVC x64 编译、Clippy、免安装 ZIP 和真实 Win32 交互烟测。
- Android 执行单测、Lint、Release 构建、正式签名校验和 API 35 SQLite instrumentation。
- macOS 执行 Swift 全量测试、Sparkle framework/XPC 嵌入校验、应用签名校验，并在 Release 中生成签名 `appcast.xml`。
