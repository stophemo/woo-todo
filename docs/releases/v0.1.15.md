本版修复 macOS `v0.1.14` 安装包无法启动的问题，并完善三端自动检查更新的触发与限频策略。

## macOS 启动修复

- 修复主程序缺少 `@executable_path/../Frameworks` 运行时搜索路径的问题；Sparkle framework 现在可从 App 内正确加载。
- 打包脚本会在签名前补齐并验证 RPATH，同时确认 Sparkle 主程序完整存在。
- CI 与正式发布流程新增相同校验，缺少 RPATH 的 macOS 包将无法进入 Release。
- `v0.1.14` 的 macOS 包无法启动，也不能通过应用内更新自救；macOS 用户需要手动安装本版一次。

## 自动检查更新

- 三端都会在冷启动时检查更新，并在应用从后台恢复时再次判断是否需要检查。
- macOS 与 Windows 在系统唤醒后也会触发检查资格判断。
- 成功检查后 12 小时内不再重复请求；检查失败后 15 分钟可重试。
- 定时器仅用于低频触发资格判断，不会绕过成功检查与失败重试的双重限频。

## 下载说明

- `Woo-Todo-v0.1.15-android.apk`：Android 13+ 安装包，使用项目长期 Release 签名。
- `Woo-Todo-v0.1.15-macos-arm64.zip`：内含 Apple Silicon `Woo Todo.app`，当前仍为 ad-hoc 签名且未经过 Apple 公证。
- `Woo-Todo-v0.1.15-windows-x64.zip`：内含单个原生 `WooTodo.exe`，免安装、无需 .NET，当前未做 Authenticode 签名。

Android 与 Windows 的 `v0.1.14` 可直接使用应用内更新升级到本版。macOS 用户需要手动替换一次损坏的 `v0.1.14`；安装 `v0.1.15` 后，后续版本可恢复使用 Sparkle 应用内更新。
