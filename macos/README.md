# Woo Todo macOS 原生客户端

这是面向 macOS Tahoe 26 的轻量原生客户端，使用 AppKit、SwiftUI 和系统 SQLite，未引入第三方运行时。Package 最低兼容 macOS 15，当前目标设备为 Apple M4 MacBook Air。

## 当前能力

- 任务模型：标题 + 可选标签 + 可选任务日期 + 可选结束日期 + 可选每天重复；单日任务不需要结束日期，无日期的一次性任务完成即止；每天重复任务过期后会把未完成项记为放弃并生成下一条。
- 统一任务列表，按已逾期、今天、接下来、未安排、今天完成分组；组内按任务时间从近到远排列，时间相同时再按标签优先级，未安排任务排在最后。标签默认只有“未分类”，任务页右上角和任务编辑器提供“＋ 新建标签 / 管理标签”，支持新建、改名、删除和上下移动调整优先级。
- 统计页展示本周完成、连续天数、按时率、进行中、14 天完成趋势、近 30 天标签分布和最近完成。
- SQLite 本地优先仓储和悬浮面板 `TodayStore`。
- 透明毛玻璃 `NSPanel` 默认作为桌面层小组件，跨桌面空间并记住位置；也可切换为普通或始终置顶任务板，并支持鼠标穿透。桌面小组件默认位于 Finder 图标下方，新增桌面文件不会被遮住；指针移入面板时临时抬到图标上方以保持可点击。
- 七项可自定义全局快捷键：默认 `Shift + Option + 1` 快速新增、`Shift + Option + 2` 显隐任务板、`Shift + Option + 3` 穿透、`Shift + Option + 4` 置顶、`Shift + Option + 5` 小组件模式、`Shift + Option + ↑/↓` 增减透明度；菜单栏始终保留恢复入口。
- 桌面小组件可直接点击勾选完成任务，也可拖动右下角自定义宽高，并自动保存位置与尺寸。
- 快速新增包含标题和标签输入；标签留空表示无标签，输入已有名称会匹配，输入新名称会自动创建。标题下方可展开“日期与提醒”，按需设置任务日期、可选结束日期和当天提醒时间；该区域默认折叠，正常快速记录不受打断。
- 桌面小组件在“今天”之外增加“接下来”分组，未来日期的任务（包括由 MCP 创建的任务）也会显示；顶部完成进度仍只统计今天。
- 快速新增面板在失去焦点（点击其他区域或切换应用）时自动收起；设置窗口保持独立，按 ⌘W 关闭，不会因为切换应用自动消失。
- 跨设备同步统一使用自行部署的 Worker 同步空间：首台设备用部署者邀请码建立空间，其他设备用六位配对码双向加入。没有内置 Worker 地址时，每台新设备首次配对前需手填一次同一个 HTTPS 地址。配对码 5 分钟内有效；两端核对同一个六位核对码后完成绑定，同步全程自动进行，设置页同时提供“立即同步”。
- 菜单栏“打开 Woo Todo”或 `⌘0` 按需打开独立主窗口；`⌘W` 收起，菜单栏可再次打开。主窗口或设置窗口可见时临时显示 Dock 图标，全部收起后回到纯菜单栏应用；窗口隐藏时暂停仓储刷新和列表渲染，后台 CPU 接近 0。
- 主窗口包含今天、全部任务、历史、统计和最近删除五个分区，底部“设置…”打开独立设置窗口；设置窗口包含显示、提醒、快捷键、跨设备、MCP 服务、本机数据。
- “设置 → 提醒”可开启每日晚间提醒并选择时间；到点后用一条本地通知汇总明天要进行、明天开始或已经逾期的待办。该开关按设备保存，不随同步空间下发。
- 删除待办会在本机保留一份恢复快照。删除仍按现有 tombstone 同步到其他设备；在任一保留过快照的设备上恢复时，会以一条新任务重新入队，其他设备像收到新增任务一样同步出现。删除待办的恢复副本不会进入备份，也不会上传到云端；同一任务如果在两台设备上同时离线恢复，可能各自生成一条新任务，手动保留一条即可。
- “MCP 服务”可开放仅监听 `127.0.0.1` 的本机 MCP 服务，让 Claude Code、Codex、Pi、Hermes、Cursor、VS Code 等本机 Agent 通过带令牌的 HTTP 接口直接新增任务、查询任务和标签。服务不会暴露到局域网或互联网，关闭开关立即停止。
- “本机数据”页可以清除全部本机数据，或清除后把 App 移入废纸篓；直接拖拽卸载 `.app` 不会自动清理数据。
- 设置窗口的“跨设备”分区支持首台设备用部署者邀请码建立同步空间，其他设备显示或输入六位配对码加入；已配对后可查看设备列表、移除设备和退出此同步空间。
- 无传统账号的设备绑定；Worker 同步凭据以本机 AES-256-GCM 加密文件保存并自动回填，密钥优先由 Secure Enclave 保护。旧版 Keychain 项只在首次迁移时读取一次，之后更新不再因 ad-hoc 签名变化反复请求钥匙串授权。
- 任务标签定义随同步空间传播；今日标题、副标题和计时模板仍只保存在本机。
- SQLite 加密 outbox、Worker 增量 cursor、幂等远端应用和 tombstone 删除同步；升级时会清理旧 WebDAV 幂等表。
- 启动、本地修改和 15 分钟低频兜底触发同步；系统唤醒和网络恢复时也会继续积压任务。失败不阻塞本地操作。
- 同步空间提供已绑定设备列表和远端撤销；当前设备可退出空间，本机任务保留。
- 升级后局域网与 WebDAV 入口已移除，已经配置好的 HTTPS Worker 同步身份可以继续使用；检测到局域网/WebDAV 旧凭据或旧同步文件时只提示一次，不删除旧凭据、不启用旧方式，本地任务保留。

## 跨设备同步

同步不是使用 Woo Todo 的前置条件；任务始终先写入本机 SQLite。需要跨设备时，macOS 与 Android 统一连接同一个自行部署的 Cloudflare Worker + D1 同步空间。

1. **首台设备建立空间**：打开“设置 → 跨设备”，填写部署者提供的邀请码；如果构建时没有内置 Worker 地址，再填写一次 HTTPS 地址。邀请码只随创建请求发送，不会保存。之后每台新设备首次配对前也需要填写同一个 HTTPS 地址；只有内置了地址的构建才能仅凭六位码加入。
2. **已有设备显示配对码**：在“显示配对码”中生成六位码，让新设备输入；新设备认领后，两端核对同一个六位核对码，再由本机确认绑定。
3. **新设备显示配对码**：在新设备上选择“显示我的配对码”，本机输入这六位码并核对设备名称与核对码，确认后批准加入。
4. **日常同步**：配对完成后自动同步任务、标签和历史；“立即同步”可以手动触发。断网不影响本地操作，恢复网络后自动补齐。

配对码 5 分钟内有效。已配对设备可在同一页查看同步空间、设备列表与最近同步状态，移除其他设备，或选择“退出此同步空间”。退出会清除本机同步凭据并停止同步，本地任务保留。

旧版的局域网与 WebDAV 已停用，Worker 同步空间是唯一方式；已经配置好的 HTTPS Worker 同步身份可以继续使用。升级后局域网/WebDAV 旧凭据不会被删除，也不会静默启用；检测到旧同步状态时只提示一次“旧同步方式已停用，本地任务保留，请重新配对”。

## 权限与网络

- 只需要外发 HTTPS 连接 Worker；同步不再使用本地网络、Bonjour 或局域网发现，因此无需在“系统设置 → 隐私与安全性 → 本地网络”中授权 Woo Todo。旧版本留下的本地网络授权可以关闭。
- 任务提醒与每日晚间汇总使用系统本地通知，在本机生成，不依赖同步服务。
- Worker 地址来自构建时 `Info.plist` 的 `WooTodoSyncEndpoint`，允许为空。为空时，首台设备在设置页手填 HTTPS 地址并保存在本机；之后配对和设备同步沿用凭据里的地址。

## 构建与测试

```bash
cd macos
swift build
swift test
swift run woo-todo-mac
```

命令行工具链与系统 SDK 必须匹配。如果机器上同时存在多套 SDK，可通过 `xcode-select` 选择已配套的 Xcode 或 Command Line Tools。

## 代码分层

- `WooTodoCore`：领域模型、任务日期状态、列表分组、统计引擎、仓储协议、`TodayStore` 与 `DashboardStore`。
- `WooTodoStorage`：SQLite 表结构、迁移、任务与标签仓储实现。
- `WooTodoSync`：本机加密凭据、Keychain 迁移、AES-GCM/X25519、六位码配对、API 客户端、同步协调器与运行时状态机。
- `WooTodoMacApp`：AppKit 生命周期、悬浮面板、独立主窗口与设置窗口、菜单栏、全局快捷键、最近删除、本机数据清理、同步运行时、本机 MCP 服务和 SwiftUI 界面。
- 四组测试覆盖任务日期与可选结束日期、列表排序、晚间提醒汇总、统计、持久化、加密协议、同步分页与配对状态机。

任务始终先保存到本地，不需要网络或同步服务即可使用。跨设备同步使用自行部署的 Cloudflare Workers + D1 同步空间：首台设备用部署者邀请码建立空间，其他设备只用六位配对码加入。macOS 通过 Sparkle 的 Ed25519 签名源完成应用内更新；GitHub Release 在未配置 Developer ID 时仍使用 ad-hoc 签名且没有 Apple 公证。同步凭据保存在本机加密文件中；首次从旧版本迁移时会读取一次旧 Keychain 项，之后更新不再因签名变化反复请求 Keychain 授权。macOS 与 Android 都会为设置了提醒时间的待办安排各自的本地通知，并支持可选的每日晚间任务汇总。

## 本机 MCP 服务

在设置窗口打开“MCP 服务”，开启“开放 MCP 服务”。Woo Todo 会在设置页显示的 `http://127.0.0.1:<五位随机端口>/mcp` 提供一个无状态的 MCP Streamable HTTP 服务，仅限本机其他 Agent 调用，所有请求都需要页面中显示的 Bearer 令牌。服务运行在 Woo Todo 进程内，不额外启动后台进程；多个 Agent 共用同一个地址，Woo Todo 退出或关闭开关后立即停止。任务仍先写入本机 SQLite，不会把任务明文发送到云端。

可用工具：

- 查询：`list_tasks`（状态、标签、标题、日期筛选与分页）、`get_task`、`list_tags`、`list_trash`、`get_statistics`。
- 任务：`add_task`、`update_task`、`complete_task`、`reopen_task`、`abandon_task`、`delete_task`、`restore_task`、`purge_trash`、`clear_history`。
- 标签：`create_tag`、`rename_tag`、`delete_tag`、`reorder_tags`。

任务工具返回完整字段、真实 UUID、标签、日期状态和时间戳。`pending` 可编辑、完成、放弃和删除；`completed` 可撤销完成；`pass` 是最终状态。删除会进入最近删除并由 `restore_task` 恢复为新任务；`purge_trash` 与 `clear_history` 是永久操作，必须显式传 `confirm=true`。标签名称忽略大小写，最多 8 个（含“未分类”），名称最长 12 个字符。

Claude Code、Codex、Pi、Hermes 可以直接执行页面中复制的命令；Cursor、VS Code 等客户端可复制页面生成的 JSON 配置。令牌相当于本机密码，重新生成后需要更新所有客户端配置。

> `v0.2.4` 起任务正文使用新的标签和日期语义，v0.2.3 及更早客户端无法正确理解。`v0.2.7`、`v0.2.8`、`v0.2.9`、`v0.2.10`、`v0.2.11`、`v0.2.12`、`v0.2.13`、`v0.2.14`、`v0.2.15`、`v0.2.16`、`v0.2.17`、`v0.2.18`、`v0.2.19` 与 `v0.3.0` 可以同步；`v0.2.6` 及更早客户端会把“未分类”固定在最前，不保留自定义排序位置，建议两端同时升级。`v0.3.0` 起 macOS 只支持 Worker 同步空间，局域网与 WebDAV 同步入口已移除。
