工作方式

任务从计划走到完成

功能围绕每天真正会用到的动作展开，不要求先搭一套复杂的项目系统。

01

先写下要做的事

任务只需要标题，标签和起止日期都可以留空。新增时直接输入标签：匹配已有名称就复用，新名称自动创建，留空就是无标签；管理标签时可以拖动手柄或上下移动调整优先级，高优先级标签的任务会排在列表更前面。

02

手机记录，电脑执行

Android 提供统一任务列表、定时提醒和桌面 Widget；Mac 通过菜单栏、快捷键与悬浮任务板承接执行。

03

看见完成节奏

统计页展示本周完成、连续天数、按时率、14 天趋势与标签分布，历史记录可以多选清理。

04

让 Agent 直接写入计划

macOS 的“MCP 服务”提供仅监听本机回环地址的服务，端口为五位随机端口且会避免常见冲突；Claude Code、Codex、Pi、Hermes、Cursor、VS Code 等 Agent 可以查询、新增、编辑、完成、撤销、放弃、删除和恢复任务，管理标签并读取统计；访问需要令牌，任务仍只保存在本机。

跨设备同步

一个 WebDAV 账号，连接所有设备

macOS 与 Android 统一使用 WebDAV 同步：坚果云、Nextcloud、群晖或自定义服务都可以。每台设备先配置同一个 WebDAV 账号，之后只用六位配对码双向加入；任务正文端到端加密，供应商只能看到密文与配对所需的公开信息。旧 Worker 与局域网同步已停用，本地任务保留。

Mac 本地任务库 · 六位码配对
WebDAV · AES-256-GCM ☁
Android 本地任务库 · 六位码配对
01

供应商自选

坚果云、Nextcloud、群晖或任何兼容的 HTTPS WebDAV 服务；所有设备使用同一个账号与目录。

02

端到端加密

任务正文与标签以 AES-256-GCM 密文写入 WebDAV；同步密钥只在本机，供应商无法解密。

03

六位码配对

已有设备显示配对码，新设备输入；也可以反向输入。持有空间的一方看到加入方设备名后点一次「批准加入」，加入方自动完成，配对码 5 分钟内有效。两方都有空间时，加入方选择以哪台设备的数据为准。

  1. 1每台设备先配置同一个 WebDAV 账号
  2. 2用六位配对码加入，持有空间方点一次批准
  3. 3启动、本地修改和每 15 分钟自动同步

WebDAV 没有服务端推送，其他设备的变更会在下次同步时到达。各设备会写入加密心跳，可在应用内查看设备名、平台与最近同步时间；这是尽力而为的名册，不能远程吊销。退出空间只清除本机身份，要阻止旧设备继续同步请修改 WebDAV 应用密码。

断网仍可正常编辑，恢复网络后自动补齐；供应商的请求频率与流量限制可能影响同步速度。
