三端怎么用，数据怎么走

01

MACOS

从菜单栏控制任务板

  1. 启动后看屏幕右上角菜单栏的清单图标；应用不会出现在 Dock。
  2. 在任何应用中按 ⇧⌥1 唤起快速新增框；Enter 创建今日主线任务，Esc 取消。
  3. ⇧⌥2 显隐任务板；⇧⌥3 切换置顶，菜单内也可开关“毛玻璃”并选择日常不透明度。
  4. ⇧⌥4 独立切换鼠标穿透；不透明度保持当前设置，再按一次恢复并聚焦。

四项全局快捷键都可在“设置… → 快捷键”中自定义；鼠标穿透与透明度彼此独立，发生冲突时也可从菜单栏执行对应操作。

02

ANDROID

睡前先打开“明日”

  1. 顶部选择“明日”，点右下角 + 连续写下第二天的任务。
  2. 长按三星桌面空白处，选择“组件 → Woo Todo”，添加今日任务组件。
  3. 列表与 Widget 可直接勾选完成；当前周期内误点时，再点一次即可撤销。

默认每天 23:10 提醒规划；通知权限被关闭时，系统不会显示提醒。

03

WINDOWS

解压即用，托盘常驻

  1. 解压 Windows ZIP，运行根目录中的 WooTodo.exe；无需安装 .NET、运行库或安装器。
  2. 任务板支持新增、完成、取消完成、置顶和穿透；托盘可恢复窗口并检查更新。
  3. 任务与设置保存在 %LOCALAPPDATA%\Woo Todo，移动或更新 EXE 不会清空数据。

当前 EXE 未做 Authenticode 签名，SmartScreen 可能提示来源未知；请只从本仓库 Release 下载并核对 SHA-256。

04

JIANGUOYUN SYNC

坚果云自动同步

  1. 先安装并登录坚果云官方客户端确认账号可用，再在网页“账户信息 → 安全选项 → 第三方应用管理”创建应用密码；网页端只用于安全设置。
  2. Mac 打开“设置… → 同步 → 坚果云自动同步”，填写账号和应用密码，保存并等待连接成功。
  3. 连接成功后二维码默认隐藏；在 Mac 显式点击“显示 Android 配置二维码”。
  4. Android 在 Woo Todo 中选择“更多 → 扫描 Mac 配置二维码”，确认预填配置并保存；手机会生成本机独立设备 ID。

配置二维码严格包含 username、appPassword、vaultId 与 vaultKey，等同坚果云 WebDAV 与 Woo Todo 的完整敏感凭据。 它不含固定端点或 deviceId，只能在两台设备近旁展示，用完立即隐藏；Woo Todo 不会上传或记录二维码和完整配置链接。任务先写入本地，坚果云只保存 AES-256-GCM 密文。

克制，但不缺关键能力

为每天重复使用而设计

不引入笔记、附件和复杂项目管理。把资源留给任务本身，也把系统资源还给电脑和手机。

A

三端原生，轻量常驻

macOS 使用 AppKit + SwiftUI，Android 使用 Kotlin + RemoteViews，Windows 使用 Rust + Win32。Windows 直接调用 Rust 共享核心中的任务规则、SQLite 仓储语义与通知计划，三端均不携带跨端 UI 运行时。

原生
B

本地优先，网络不挡路

新增、修改、完成和排序只依赖本地 SQLite，三端断网时都能照常工作；macOS 与 Android 恢复联网后可继续自动同步。

离线可用
C

日、周、月与闲时

时间维度与主线、支线、外传交叉使用；重复任务、历史、Pass 和履约趋势都包含在内。

清晰分层
D

误点可撤销，设置可同步

三端都能在当前周期内取消误点完成；macOS 与 Android 的今日标题、副标题、起始日和截止日可随任务一起加密同步。

允许纠错
E

一次点击完成后续更新

macOS、Android 与 Windows 都可在应用内下载并校验后续正式版；平台安装确认和安全提示仍会保留。

应用内更新
F

无传统账号，加密备份

macOS 与 Android 无需 Woo Todo 账号，可使用加密的 .wootodo 恢复备份；Windows 当前聚焦本地任务，暂不支持同步和加密备份。

macOS 与 Android：坚果云密文自动同步

任务明文只留在设备里

macOS 与 Android 始终先读写本地 SQLite。启用坚果云后，任务和显示设置会写成 AES-256-GCM 密文对象并自动同步，云端只能看到同步所需的实体标识、逻辑时钟和密文大小等元数据。暂时断网时改动留在本地，恢复联网后继续同步；Mac 局域网和自建 Worker + D1 也是可选方案。Windows 当前不参与跨端同步。
