工作方式

任务从计划走到完成

功能围绕每天真正会用到的动作展开，不要求先搭一套复杂的项目系统。

01

先写下要做的事

任务只需要标题，标签和起止日期都可以留空。新增时直接输入标签：匹配已有名称就复用，新名称自动创建，留空就是无标签；管理标签时可以拖动手柄或上下移动调整优先级，高优先级标签的任务会排在列表更前面。

02

手机记录，电脑执行

Android 提供统一任务列表、定时提醒和桌面 Widget；Mac 通过菜单栏、快捷键与悬浮任务板承接执行。

03

看见完成节奏

统计页展示本周完成、连续天数、按时率、14 天趋势与标签分布，历史记录可以多选清理。

04

让 Agent 直接写入计划

macOS 的“MCP 接入”提供仅监听 127.0.0.1 的本地服务，Claude Code、Cursor、VS Code 等客户端可以直接调用 add_task、list_tasks、list_tags；访问需要令牌，任务仍只保存在本机。

同一网络同步

两端按自己的信任边界同步

不需要互联网、Woo Todo 账号或固定服务器地址。在 Mac 开启同步主机，Android 输入 Mac 显示的六位配对码即可加入。两端都支持显示和输入六位码；WebDAV 仍使用配置二维码或链接。同步全程自动进行。
