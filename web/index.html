工作方式

任务从计划走到完成

功能围绕每天真正会用到的动作展开，不要求先搭一套复杂的项目系统。

01

先分清时间和轻重

按今日、本周、本月与闲时安排任务，再用主线、支线、外传区分优先级。重复任务会在下一个周期继续出现。

02

手机安排，电脑执行

Android 提供今日与明日规划、提醒和桌面 Widget；Mac 与 Windows 通过菜单栏、快捷键与悬浮任务板承接执行。

03

本地记录，随时可用

新增、修改、完成与排序直接写入本机。断网时继续工作，恢复连接后再同步积压变化。

同一网络同步

三端按自己的信任边界同步

不需要互联网、Woo Todo 账号或固定服务器地址。在 Mac 或 Windows 开启同步主机，Android 扫描二维码或粘贴配对链接即可加入。

电脑热点

手机连接电脑开启的热点。

  1. 1Mac 开启“同一网络同步”
  2. 2Android 扫描配对二维码
  3. 3同网时自动同步任务和设置

需要跨网络时，可改用第三方 WebDAV 或 自建服务。
